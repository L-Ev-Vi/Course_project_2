## Учебный проект Course_prodject_2
# *Интеграция с внешним сервисом HeadHunter.ru*
*В проекте написана программа, которая получает информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.*

### Структура проекта
+ main.py — модуль, в котором реализованна функция взаимодействия с пользователем.
+ src/aip_hh.py — модуль, который выполняет подключения к API HH.ru для получать вакансии.
+ src/aip_request_error — модуль, который отвечает за обработку исключений когда код состояния HTTP не равен 200.
+ src/base_file_saver.py — модуль, в котором описан абстрактный класс для работы с файлами.
+ src/base_filling_in_data.py — модуль, в котором описан абстрактный класс для заполнения данных.
+ src/base_parser.py — модуль, в котором описан абстрактный класс для работы с API сервисами.
+ src/currency_exchange.py — модуль, который выполняет API запрос на внешний сервис для получения актуального курса валют, и возвращает сумму переданной валюты относительно 'RUB'.
+ src/filling_in_job_information.py — модуль, который заполняет данные о вакансии при её создании.
+ src/filling_in_request_data.py — модуль, который заполняет данные о поисковом запросе для взаимодействия с пользователем при выполнении поиска по вакансиям на платформе hh.ru.
+ src/get_top_vacancies.py — модуль, который возвращает количество вакансий для вывода в топ.
+ src/greeting_time_day.py — модуль, который возвращает приветствием относительно времени суток.
+ src/json_saver.py — модуль, который предоставляет возможности для работы с json-файлом: создание, добавление, удаление.
+ src/print_vacancies.py — модуль, который принимает список с топ вакансиями по ЗП и выводит их в виде строк.
+ src/sort_vacancies.py — модуль, который сортирует список вакансий по значению заработной платы, согласно указанного порядка.
+ src/vacancy.py — модуль, который предоставляет возможности для работы с вакансиями: создание, сравнение, вывод информации.
+ src/xlsx_saver.py — модуль, который предоставляет возможности для работы с xlsx-файлом: создание, добавление, удаление.
+ data/ — директория в которой хранятся файлы содержащие информацию о вакансиях.
+ tests/ — пакет с модулями для проверки работоспособности и отладки ПО.
+ .env_template — файл для конфигурации с базами данных.

### Тестирование
Проверка работоспособность программы проводится в пакете `tests`, структуру которой составляют:
- модуль `conftest.py` для хранения фикстур;
-  и тестируемые модуль `test_api_hh.py, test_currency_exchange.py, test_filling_in_job_information.py, test_filling_in_request_data.py, test_get_top_vacancies.py, test_greeting_time_day.py, test_json_saver.py, test_print_vacancies.py, test_sort_vacancies.py, test_vacancy.py, test_xlsx_saver.py`

- В модуле задаются параметры для функций, и проводится отработка сценариев поведения программы.
- Для проведения тестов используется фреймворк `pytest`, он устанавливается вместе с зависимостями проекта, но также 
возможно выполнить установку через команду: `poetry add --group dev pytest`
- Запуск тестов производится через команду `pytest` (или конфигурацию используемой IDE)

Для формирования отчёта о том какое количество кода охвачено тестами в процентном соотношении, устанавливается библиотека 
'pytest-cov' через команду: `poetry add --group dev pytest-cov`

Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:
+ `pytest --cov` — при активированном виртуальном окружении.
+ `poetry run pytest --cov` — через poetry.
+ `pytest --cov-report term-missing --cov=src` — проверка покрытия тестом с выводом строк
+ `pytest --cov=src --cov-report=html` — чтобы сгенерировать отчет о покрытии в HTML-формате
  - при последнем варианте был сгенерирован отчет `index.html` который храниться в папке `htmlcov`.
